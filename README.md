# 🛒 UrbanCart Retail Analytics Dashboard

An interactive **Retail Analytics Dashboard built in Microsoft Excel** to analyze sales, profitability, customer orders, product performance, regional performance, and delivery/return trends.

The project transforms raw retail data into an interactive business dashboard using **Excel Data Model, Power Pivot, PivotTables, DAX Measures, Slicers, and Data Visualization**.

## 🎯 Project Objective

The main objective of this project is to help a retail business understand its overall performance and identify important business trends through an interactive dashboard.

The dashboard provides insights into:

- Overall sales and profit performance
- Monthly sales and profit trends
- Regional performance
- State-wise sales performance
- Product and category performance
- Customer and order activity
- Delivery status
- Return rate
- Top-performing products
- Top-performing states

---

## 🏢 Business Problem

UrbanCart generates a large amount of sales and order data, but raw data alone does not provide an easy way to understand business performance.

Management needs answers to questions such as:

- How much revenue is the business generating?
- How profitable is the business?
- Which regions are performing best?
- Which states generate the highest sales?
- Which products contribute the most revenue?
- What is the monthly sales trend?
- What percentage of orders are returned?
- What is the distribution of delivered, returned, and cancelled orders?
- Which categories and products require more attention?

This dashboard was created to answer these questions in a simple and interactive way.

---

## 📌 Key Performance Indicators

The dashboard includes the following KPIs:

- **Total Sales**
- **Total Profit**
- **Profit Margin**
- **Total Orders**
- **Total Customers**
- **Return Rate**

The KPIs are connected to the Excel Data Model and dynamically respond to dashboard slicers.

---

## 🔍 Dashboard Features

### 1. Sales & Profit Analysis

Analyze overall revenue and profitability and track monthly performance trends.

### 2. Regional Analysis

Compare sales performance across different regions.

### 3. State-wise Sales Analysis

Identify the highest-performing states based on sales.

### 4. Product Analysis

Analyze top-performing products and identify products contributing the highest revenue.

### 5. Category Analysis

Compare sales performance across different product categories.

### 6. Order Status Analysis

Analyze the distribution of:

- Delivered
- Returned
- Cancelled

orders.

### 7. Return Rate Analysis

The dashboard uses a dynamic DAX measure to calculate Return Rate:

**Return Rate = Returned Orders / Total Orders**

The measure automatically changes when filters or slicers are applied.

## 🎛️ Interactive Filters

The dashboard includes interactive slicers for:

- **Category**

These slicers dynamically update the KPIs, charts, and analysis throughout the dashboard.
